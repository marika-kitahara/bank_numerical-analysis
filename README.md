後方数値データ分析アプリ

概要

Streamlit製の営業分析ツール。
後方数値データを媒体・セグメント・メルマガ・アロケーションまで一元分析します。

主な機能

-   媒体分析
-   クロス分析
-   セグメント分析
-   勝ちパターン分析
-   アロケーション試算
-   メルマガ分析

入力データ

単一Excel内 - 後方数値データ - 媒体コードマスタ - コストデータ

技術構成

-   Python
-   Streamlit
-   pandas
-   openpyxl
-   Altair

データ処理

1.  Excel読込
2.  シート選択
3.  マスタ結合
4.  コスト補完
5.  KPI計算
6.  集計
7.  グラフ表示

コストロジック

AK列にコストが存在する場合はその値を利用。
存在しない場合はコストデータシートから
月×小項目単位で取得し、申込件数按分で補完。

アロケーション

中項目＋小項目を単位として予算移管を試算。
CPA・件数・承認率・投下倍率などへの影響を算出。

メルマガ分析

-   キャンペーン比較
-   小項目比較
-   セグメント別比較
-   指標別グラフ2種類表示
